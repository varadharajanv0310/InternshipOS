## Coverage limits

No measured market recall or guarantee of all useful internships. Bounded result windows, blocks/rate limits, incomplete company mappings, unsupported pages, referrals, private openings and unclear requirements can cause misses. ATS title/description heuristics can misclassify. These sources complement each other; source count is not a coverage percentage.

Collection is scheduled every six hours in GitHub Actions, with at most 64 due sources per run. Individual source cadences and backlog determine freshness; scheduled runs may be delayed by GitHub. It is not continuous minute-by-minute scanning.
