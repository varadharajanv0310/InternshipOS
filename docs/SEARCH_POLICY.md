# Personal search policy

Personal profile facts are stored privately in the owner workspace. Primary targets: software engineering, data science/data engineering and AI/ML internships.

## Explicit keyword searches

Software engineer intern; backend developer intern; frontend developer intern; full stack intern; data science intern; data engineer intern; machine learning intern; AI intern; NLP intern; research intern; SDE intern; software engineering internship; research assistant; software apprentice. Each is registered for India on LinkedIn and Indeed with a bounded 30-result window.

Employer boards collect broader inventories and classify downstream. Additional discovery: Internshala eight technical categories across Chennai and work-from-home India, and 2027 SWE/AI international GitHub trackers. Both trackers returned data in live checks (495 SWE and 539 AI leads; global raw leads, not eligible internship counts).

Default shortlist families are SWE/Data/AI_ML. Exclusions include WordPress, manual QA/testing, IT support/helpdesk, UI/UX/graphic design, 3D artist, commercial GTM/business strategy, and financial/investment analyst titles. Employer AI/software boilerplate cannot make a commercial job technical. Generic research results must pass a technical-family check. Security/software research can qualify through SWE/AI. Broad global-remote leads remain eligibility review items.

Hosted collection keeps Bengaluru/Bangalore, Chennai, remote explicitly open to India, and India-unspecified technical internships/apprenticeships. Other cities and PhD-only titles are excluded. Unknown/global remote leads remain review items and do not enter the strict personal feed. Known foreign roles are not retained anew. Existing records are preserved during source updates, so closure evidence is not corrupted by this storage filter. Local archive is preserved.

## Coverage limits

No measured market recall or guarantee of all useful internships. Bounded result windows, blocks/rate limits, incomplete company mappings, unsupported pages, referrals, private openings and unclear requirements can cause misses. ATS title/description heuristics can misclassify. These sources complement each other; source count is not a coverage percentage.

GitHub Actions provides two scheduled trigger opportunities per hour, at minutes 17 and 47, with a selection ceiling of 384 due sources and six concurrent collectors. A 26-minute launch budget preserves unfinished work. Each source has a 90-second window and 40-detail budget; purely budget-limited saved cursors can continue after 30 minutes without changing owner cadence or real failure backoff. Paced public LinkedIn searches occupy at most two slots per wave. Individual source cadences, actual worker timing and backlog determine freshness; scheduled events may be delayed or dropped. This is bounded repeated scanning, not guaranteed continuous service.

Company priority is the default ordering. It is an editable employer preference, separate from role fit, job value, verification and application success probability. Previous tracker source lists supply candidates, while InternshipOS owns the normalization, filtering, live verification, scoring and lifecycle rules.
